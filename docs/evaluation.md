## 1. 为什么要做多重检验校正（multiple-testing correction）

试的策略越多，纯靠运气跑出一个漂亮 Sharpe 的概率就越高。在 N 个毫无真实收益的策略里挑最好的那一个，它的 Sharpe 期望值会随 N 上升。不扣除这部分"挑选红利"，回测的显著性就是虚高的（选择偏差，selection bias / backtest overfitting）。

## 2. Deflated Sharpe Ratio（Bailey & López de Prado, 2014）

**纯噪声下的预期最大 Sharpe（年化）：**

SR0 = √V · [ (1−γ)·Φ⁻¹(1 − 1/N) + γ·Φ⁻¹(1 − 1/(N·e)) ]

- N：累计试验次数（trial count）
- V：各试验年化 Sharpe 的跨试验方差（variance of trial Sharpes）
- γ ≈ 0.5772：欧拉–马斯刻若尼常数（Euler–Mascheroni constant）
- Φ⁻¹：标准正态分位函数

**DSR：**

DSR = Φ( (SR − SR0′)·√(n−1) / √(1 − skew·SR + (kurt−1)/4·SR²) )

- SR：**每期**（per-period）Sharpe，不是年化值
- SR0′ = SR0 / √ppy（ppy：每年期数，日频为 252）
- n：观测期数；skew：偏度；kurt：**原始峰度**（raw kurtosis，正态为 3，不是超额峰度）

DSR 可理解为"真实 Sharpe 高于纯噪声最好结果"的概率。

### 每年期数（ppy）

市场枚举须用小写：`cn_a`, `hk`, `us`, `crypto`, `futures`, `fx`, `demo`。演示代码默认值：

| market | ppy |
|---|---|
| cn_a | 242 |
| hk | 246 |
| us | 252 |
| crypto | 365 |
| futures | 242 |
| fx | 260 |
| demo | 252 |

未知市场会直接报中文错误，不静默回退。**注意**：这些是演示默认值，最终 ppy 应从 `markets/` 配置的 `periods_per_year` 字段读取。

### 年化口径一致（ppy consistency）

- 每条试验记录须带 `market` 字段，由它决定 ppy。
- 同一组周期型试验必须使用**同一个 ppy**。例如 crypto（365）与 cn_a（242）混在一组时，`estimate_variance` 和 `deflated_sharpe` 会直接报中文错误：年化口径不同，Sharpe 不可比，应按市场分组分别计算。
- DSR 中把年化 SR0 换算为每期（SR0/√ppy）时，所用 ppy 必须与这组试验自身年化时所用的 ppy 相同；`deflated_sharpe(..., trials=...)` 会检查这一点，不一致即报错。

## 3. 通过规则

DSR ≥ 0.95 是**附加**门槛，与以下门槛同时满足，**不替代**其中任何一条：

1. 样本量 n ≥ 30
2. |t| ≥ 2.4
3. 扣除交易成本后的超额收益 > 0（净值口径，net of cost）
4. DSR ≥ 0.95

## 4. 试验计数规则（trial counting）

- 每调用一次评分器（scorer）= 一次试验，**包括失败的、重跑的、改参数的**。
- N 只增不减，**永不重置**；换个文件夹、换个名字重来都不算重置理由。
- 开新一轮之前，先公开宣布本轮预算 B（最多再试几次），用完即停。
- **demo 不持久化 N，只加不减靠登记表保证。** 本演示代码每次运行都在内存里重新计数；真实系统必须使用只追加的试验登记表（append-only trial registry）：每次评分器调用写入一行，不改、不删，N 由登记表行数得出，而不是由研究者自报。

## 5. 方差 V 的估计

- 只用**周期型**试验（ppy > 1）且 n ≥ 30 的试验估计 V。
- 事件型试验必须显式标记 `kind: 'event'`；不能用 `ppy=1` 之类的改写把周期型试验"变成"事件型。有 `market` 时，`ppy` 与该市场默认值冲突会直接报中文错误。
- **事件型**试验（如按公告触发、一年几次）和小样本试验：**计入 N，不计入 V**——它们的年化 Sharpe 噪声极大，会把 V 扭曲。
- V 必须用**全部可比试验**（all comparable trials）计算，包括亏损的、被放弃的，**不能只用赢家**。只拿表现好的几个算方差，会系统性低估 V，从而压低 SR0。
- V 设下限 V_floor = 0.25（即年化 SR 标准差 0.5）。原因：当试验高度相似（只微调参数）时，样本方差会很小，SR0 被低估，门槛形同虚设；下限保证门槛不会因"试得太像"而变松。

## 6. SR0 参考表（V = 0.25，示例数据，由脚本计算）

| N | SR0（年化） |
|---|---|
| 12 | 0.832 |
| 30 | 1.037 |
| 90 | 1.247 |
| 150 | 1.335 |

试 150 次后，年化 Sharpe 需明显高于 1.3 才有意义。

## 7. 常见陷阱（pitfalls）

- **幸存者偏差（survivorship bias）**：只用当前成分股回测，漏掉退市/被剔除的股票。应使用历史时点成分（point-in-time）。
- **前视偏差（look-ahead bias）**：用报告期而非**公告日**作为信号日；信号应在公告之后可交易的时点才入场。
- **事后改规则（changing rules post hoc）**：看到结果后再改门槛、成本或持有期——这本身就是一次新试验，必须计入 N。
- **事后挑起点（choosing start point after seeing results）**：回测区间应预先登记，不能挑"好看"的起止日期。

## 8. 合成示例：运气生成器（luck generator，示例数据）

运行 `python -m pipeline.dsr_demo`，调用 `luck_generator(seed=29)`：

- 市场为 `demo`（ppy = 252）。生成 100 个**纯噪声**日频策略：真实均值 = 0，日波动 1%，每个 504 天。它们没有任何真实收益。
- 全部 100 次都计为试验：N = 100，V = 0.505（≥ 下限 0.25），SR0 = 1.799。

**朴素排名前五（示例数据）：**

| 策略 | 年化 SR | t 值 | DSR（N=100） |
|---|---|---|---|
| NOISE-076 | +2.34 | +3.31 | 0.775 |
| NOISE-046 | +1.45 | +2.05 | 0.309 |
| NOISE-043 | +1.44 | +2.04 | 0.304 |
| NOISE-055 | +1.20 | +1.70 | 0.202 |
| NOISE-033 | +1.19 | +1.68 | 0.195 |

第一名年化 Sharpe 2.34、t = 3.31，单看足以通过 |t| ≥ 2.4 的门槛——但它是纯运气。**在 N = 100 下，100 个策略中 DSR ≥ 0.95 的数量为 0。**

**同一个策略（NOISE-076）在不同 N 下的门槛（V = 0.505，示例数据）：**

| 声称试过的次数 N | SR0（年化门槛） | NOISE-076 的 DSR | 是否 ≥ 0.95 |
|---|---|---|---|
| 1 | 0.000 | 0.999 | 通过 |
| 10 | 1.119 | 0.956 | 通过 |
| 100 | 1.799 | 0.775 | 不通过 |

同一条收益曲线，只要隐瞒了 90 次失败的试验，就能从"不通过"变成"通过"。这正是第 4 节要求 N 只增不减、失败也要计数的原因。

### 种子说明与稳健性（seed honesty & robustness）

坦白：种子 29 是从种子 1–39 中扫描后**特意挑出来的**，因为它的第一名 t 值最"好看"（3.31）。挑种子本身就是一种选择——这正是本文要警惕的行为，所以我们把它公开出来，并补上跨种子检验（`robustness()`，测试 `test_robustness_across_seeds`）：

| 种子 1–100（每个种子 100 个纯噪声策略，N=100） | 比例 |
|---|---|
| 朴素第一名 t ≥ 2.4 | 55% |
| 至少一个策略 DSR ≥ 0.95 | 0% |

也就是说：从 100 个纯噪声策略里挑出一个 t≥2.4 的"显著"策略，大约是抛硬币的概率；但只要老实计入 N=100，DSR 在 100 个种子里一次都没有放行。（示例数据）
