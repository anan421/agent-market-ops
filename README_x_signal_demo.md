# x_signal_demo 入门

> **示例数据，不构成建议。** 帖子、作者（demo_user_*）和标的（DEMO-X / DEMO-Y / DEMO-Z）全部是虚构的。

这份文档只讲三件事。中文帖、英文帖都支持。

## 1. 什么是一手信源
**一手 = 当事方本人说的。** 必须同时满足两条：
- 有新内容：是 `original` 原创帖，或者是加了实质内容的 `quote` 引用帖，并且不是水贴；
- `is_primary_source = true`：作者本人就是当事方，比如公司自己、项目方自己。

**路人原创**：原创帖写得再长、再有道理，只要作者不是当事方（`is_primary_source = false`），就不算一手。输出里会单独列出「路人原创」的条数，它既不算一手，也不算噪声。

## 2. 什么是噪声
其余的都算噪声：
- `repost`：纯转发；
- `reply`：回复；
- 水贴：有效长度不到 10。有效长度这样算：英文字母和数字每个算 1，汉字每个算 3，emoji 和标点不算。
  - 例子：wow = 3，链上冲！= 9，火箭🚀 = 6，这三条都是水贴。
  - 电池工厂产量翻倍 = 24，不是水贴。

## 关键词怎么匹配
- 英文关键词按单词边界（`\b`）匹配：`rocket` 能命中 "the rocket"，但不会命中 "rocketry"。这样误报少，代价是复数和变形会漏掉，比如 "rockets"。需要的话把变形也加进关键词表。
- 中文没有空格分词，所以按子串匹配：`电池` 能命中 "固态电池"。代价是偶尔会误报。

## 3. 信噪比怎么算
```
snr = 一手帖数 / 该标的的相关帖总数
```
"相关"指帖子命中了这个标的的关键词，不管是什么类型的帖子，路人原创也算在分母里。

如果 snr < 0.4，并且相关帖的总互动量 ≥ 500，就标为**共识噪声**：很多人在喊，但没人说出新东西。

每个标的都有 `market` 字段，取值只能是：`cn_a`（A股）、`hk`（港股）、`us`（美股）、`crypto`（加密）、`futures`（期货）、`fx`（外汇）、`demo`（演示）。输出里显示中文名。

## 运行
```bash
PYTHONPATH=. python3 pipeline/x_signal_demo.py              # 全部
PYTHONPATH=. python3 pipeline/x_signal_demo.py --market crypto  # 只看一个市场
```
